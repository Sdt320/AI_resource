# Transformers

Transformers are neural architectures built on attention mechanisms.

Core ideas:
- Self-attention enables global context understanding
- Encoder-decoder, encoder-only, decoder-only variants
- Positional encoding for sequential data

Strengths:
- Excellent for text, code, and multimodal tasks
- Scales well with large training data
- Supports parallel computation

Practical tips:
- Use pretrained transformer libraries like Hugging Face Transformers
- Manage memory with gradient checkpointing and model sharding
- Apply prompt engineering for generative tasks
