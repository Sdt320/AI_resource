# Machine Learning

Machine learning is the field of teaching systems to learn from data.

Key ideas:
- Supervised learning: train on labeled examples.
- Unsupervised learning: find structure in unlabeled data.
- Semi-supervised learning: combine labeled and unlabeled examples.
- Feature engineering and data preparation are critical.

Common tasks:
- Classification
- Regression
- Clustering
- Dimensionality reduction

Best practices:
- Start with simple models and validate with cross-validation.
- Track data quality, bias, and distribution drift.
- Use explainability tools where possible.
