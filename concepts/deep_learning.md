# Deep Learning

Deep learning uses neural networks with many layers to learn complex patterns.

Core components:
- Layers: dense, convolutional, recurrent, transformer
- Activation functions: ReLU, sigmoid, tanh
- Loss functions: cross-entropy, mean squared error
- Optimization: SGD, Adam, RMSprop

Important topics:
- Regularization: dropout, weight decay, batch normalization
- Transfer learning for model reuse
- Model scaling, hardware acceleration, and GPU/TPU usage
