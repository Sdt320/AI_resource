# Reinforcement Learning

Reinforcement learning teaches agents to make decisions by maximizing rewards.

Key concepts:
- Agent, environment, state, action, reward
- Policy, value function, Q-learning
- Model-free vs model-based methods
- Exploration vs exploitation

Popular algorithms:
- DQN, PPO, A3C, SAC
- Monte Carlo methods
- Temporal difference learning

Practical notes:
- Start with simple environments and clear reward design.
- Monitor training stability and reward shaping.
- Use simulation before deploying to real systems.
