# Evaluation Metrics

Common AI metrics by task:

Classification:
- Accuracy, precision, recall, F1
- ROC AUC, confusion matrix

Regression:
- MSE, RMSE, MAE, R²

NLP:
- BLEU, ROUGE, METEOR
- Perplexity, exact match

Vision:
- IoU, mAP, PSNR, SSIM

Best practices:
- Choose metrics aligned with business goals.
- Track multiple metrics for model quality and fairness.
- Validate on held-out and real-world data.
